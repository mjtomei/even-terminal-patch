# Attribution and license scope

This is an unofficial patch for `@evenrealities/even-terminal@0.8.1`, the Even
Terminal desktop bridge. It is not an Even Realities release and does not
include the phone or glasses application.

The original package is obtained directly from the [official npm
registry](https://registry.npmjs.org/@evenrealities/even-terminal/-/even-terminal-0.8.1.tgz).
Its README declares MIT. The inspected 0.8.1 archive does not supply a full
license file or a copyright notice. We do not invent an upstream holder or
year. Reconstruction retains its original README as `UPSTREAM-README.md`.

Upstream material and dependencies retain their respective terms. In particular,
the Claude Agent SDK has its own terms. Dependencies are installed separately
from the reconstructed lockfile; they are not bundled.

No upstream implementation files or archive are distributed here. COPY records
refer to bytes in the user's separately downloaded, verified upstream archive.
INSERT records identify reviewed added material. See [the audit
record](docs/AUDIT.md) for checks performed and their limits.
